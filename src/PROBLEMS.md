# Анализ проблем в проекте

## 1. ПРОБЛЕМЫ В s21_string.c

### 1.1. Отсутствующие типы и макросы
- **s21_size_t** не определен (используется, но не объявлен в s21_string.h)
- **s21_NULL** не определен (используется, но не объявлен в s21_string.h)
- Нужно добавить: `typedef size_t s21_size_t;` и `#define s21_NULL NULL`

### 1.2. Отсутствующие декларации функций в s21_string.h
Следующие функции определены в s21_string.c, но отсутствуют в s21_string.h:
- s21_memcpy
- s21_memset
- s21_memcmp
- s21_strncpy
- s21_strncat
- s21_strchr
- s21_strrchr
- s21_strcspn
- s21_strerror
- s21_memchr
- s21_strncmp
- s21_strpbrk
- s21_strstr
- s21_strtok

### 1.3. Несоответствие сигнатур
- `s21_strlen` в .c: `s21_size_t s21_strlen(char *str)`
- `s21_strlen` в .h: `int s21_strlen(const char *str)`
- Нужно унифицировать (должно быть `s21_size_t` и `const char*`)

### 1.4. Использование стандартных функций вместо s21_ версий
- **Строка 155**: `strncpy` → должно быть `s21_strncpy` (но это может быть проблемой, т.к. в s21_strerror используется для копирования строки ошибки)
- **Строка 157**: `sprintf` → должно быть `s21_sprintf` (но это может быть проблемой, т.к. в s21_strerror используется)
- **Строка 220-221**: `strlen` → должно быть `s21_strlen` (есть TODO комментарий)
- **Строка 248, 253**: `strchr` → должно быть `s21_strchr` (есть TODO комментарий)

### 1.5. Лишние комментарии для удаления
- **Строка 73**: `//strchr находит первое вхождение символа в строке`
- **Строка 87**: `//strrchr находит последнее вхождение строки`
- **Строки 97-99**: Многострочный комментарий с объяснением логики
- **Строка 117**: `//Вычисляет длину начального сегмента...`
- **Строка 123**: `//printf("%zu %zu\n", s21_strlen(str1), s21_strlen(str2));` (закомментированный код)
- **Строка 128**: `//printf("%c %c\n", str1[i], str2[j]);` (закомментированный код)
- **Строка 150**: `//Выполняет поиск во внутреннем массиве...`
- **Строка 189**: `#if 0` блок с закомментированным кодом (можно удалить)
- **Строка 190**: `// TODO strlen заменить на s21_strlen` (внутри #if 0, но можно удалить весь блок)
- **Строка 218**: `// TODO strlen заменить на s21_strlen`
- **Строка 238**: `// TODO заменить strchr на s21_strchr`

### 1.6. Проблемы с логикой
- **s21_strlen (строка 10)**: возвращает -1 при NULL, но s21_size_t - это size_t (unsigned тип), не может быть -1
- **s21_strncat (строка 68)**: не добавляет '\0' в конце (проблема стандарта)
- **s21_strncpy (строка 53-60)**: логика неправильная - должна копировать n символов, даже если встречает '\0', и дополнять '\0' если n больше длины src
- **s21_strcspn (строка 119)**: возвращает `size_t`, а не `s21_size_t` (несоответствие)

### 1.7. Отсутствующий include
- **s21_strerror** использует `s21_error_array`, `NUMBER_OF_ERRORS`, `UNKNOWN` - нужен `#include "s21_error.h"`
